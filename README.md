# SPCX 波段交易面板

Cutting Salami · 切香肠复利策略 — 手动定价、纯本地的波段交易辅助面板。

直接用浏览器打开 `index.html` 即可使用，无需构建、无需服务器。

## 功能

- **实时行情**：在 claude.ai Artifact 中打开时，通过你连接的 Interactive Brokers 连接器自动读取实时价格（默认 SPCX，可切换任意标的）；本地打开则回退为手动输入
- **📊 K 线图**：日线蜡烛图 + MA5/MA10/MA20、MACD(12,26,9)、RSI(14)，成交量、十字光标与悬浮明细，1月/3月/6月/全部区间切换
- **🎯 下一步建议**：按波段目标（默认 8%）与回补回撤（默认 5%）自动计算建议卖点与买回点，并结合 RSI 超买超卖、MA20 位置、20 日高低点给出信号
- **🔁 波段交易记录**：卖出与买回自动 FIFO 配对成回合，并自动同步持仓股数与建仓均价
- **💰 收益统计**：累计已实现利润、未实现盈亏、复利收益率（已实现 ÷ 初始本金）、总收益率
- **📉 风险指标**：标的最大回撤（图表区间）、胜率、盈亏比、平均每轮收益
- **分批卖出净利润**：¼ / ⅓ / ½ / 全仓卖出的净利润（已扣手续费）

所有输入与交易记录保存在浏览器 localStorage，仅本机可见。支持浅色 / 深色模式（跟随系统）。

> 不构成投资建议，波段操作请自行评估风险。
