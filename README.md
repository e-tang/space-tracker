# SPCX 波段交易面板

Cutting Salami · 切香肠复利策略 — 手动定价、纯本地的波段交易辅助面板。

直接用浏览器打开 `index.html` 即可使用，无需构建、无需服务器。

## 功能

- **手动输入**：当前股价、建仓均价、持仓股数、单笔交易费
- **持仓概览**：总成本、当前市值、浮动盈亏、浮盈比例
- **分批卖出净利润**：¼ / ⅓ / ½ / 全仓卖出的净利润（已扣手续费）
- **卖出后建议回补价位**：按 3% / 5% / 8% / 10% 回撤给出回补价，并以半仓卖出所得估算可回补股数与净增股数
- **波段交易记录**：记录每次卖出，自动累计已实现利润、交易次数与复利收益率

所有输入与交易记录保存在浏览器 localStorage，仅本机可见。面板不连接实时行情，价格与持仓需手动更新。支持浅色 / 深色模式（跟随系统）。

> 不构成投资建议，波段操作请自行评估风险。
